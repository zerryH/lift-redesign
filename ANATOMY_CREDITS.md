# Anatomy asset attribution

Lift's Rank anatomy map uses modified minimal male front/back SVG anatomy assets from suryamolly/muscle_mapper.

Source: https://github.com/suryamolly/muscle_mapper

The source repository is MIT-licensed. Lift adapts the SVG geometry into its 13 rank muscle groups and applies its own styling and rank-color system.

The detailed advanced assets from that project were not used.
