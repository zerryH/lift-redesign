# LiftLog Privacy Notice

**Last updated: 7 October 2026 · Build 5.5.84**

## What Lift stores

Lift stores workout history, bodyweight history, profile/ranking settings, custom exercises and calculated rank results locally on the user's device. Backups are created only when the user chooses Export.

Lift does not require an account and does not intentionally upload workout data to a Lift-owned server.

## Hosting

The public web build is hosted by GitHub Pages. GitHub states that visitor IP addresses are logged and stored for security purposes. This is hosting-provider processing and is separate from Lift's local workout database.

## Deletion

Users can clear Lift's locally stored app data with **Profile → Reset all data**, or through their browser's site/app storage controls. Exported backup files are under the user's control and can be deleted from the device like any other file.
